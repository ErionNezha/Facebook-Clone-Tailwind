# 📘 Facebook Clone (Tailwind)

Klon i ndërfaqes së Facebook-ut i ndërtuar me Tailwind CSS.

## 🚀 Live demo

https://erionnezha.github.io/Facebook-Clone-Tailwind/

Hap `index.html` — tab-i **Live Demo** ekzekutohet direkt në browser, ndërsa tab-i **Kodi Burim** tregon kodin e plotë.
